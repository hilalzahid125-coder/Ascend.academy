# ASCEND Brand Guide

## Name
**ASCEND**

School endorsement: **Peshawar Model School Boys IV**

Tagline: **Compete • Achieve • Grow**

Creator credit: **Made by Abdul Hanan Sethi**

## Identity structure
The school crest is the institutional mark and should appear in school showcase/endorsement areas. ASCEND uses its own upward `A + arrow` mark for the product itself.

## Core palette
- Orange: `#F97316`
- Dark orange: `#EA580C`
- Near black: `#111111` / `#171717`
- White: `#FFFFFF`
- Warm UI background: `#FAF9F7`

## Category accents
The layout and visual language remain consistent. Only small accents change:
- Academic: blue
- Sports: green
- Character/discipline: gold
- Activities: teal

The product should remain roughly 85–90% orange/white/black and 10–15% category accent.

## Logo
The included `static/app-logo.svg` is the application logo. It uses a rising orange `A` with a white upward arrow on a black rounded tile.

The real school crest should be uploaded from **Admin → Brand & settings** so it can be replaced without code changes.
